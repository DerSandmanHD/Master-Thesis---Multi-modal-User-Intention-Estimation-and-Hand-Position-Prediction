# Data access and disclosure boundaries

This research checkout is **not an anonymized public data release**. Participant
identifiers occur in historical paths, configurations, annotation tables,
reports, images and Git history. Labels such as P01--P25 in the thesis do not
prevent linkage through the archived fold order and source metadata. Removing a
name from the current branch alone does not remove it from Git history.

Processed tracking, embeddings and derived masters are not automatically
anonymous merely because raw RGB/audio is omitted. Access to the processed
package and checkpoints must be arranged with the project maintainer. The
maintainer must determine the permitted recipients and scope from the study's
actual consent and institutional requirements. This document neither grants
permission nor certifies consent for public redistribution.

The maintainer controls repository visibility and reviewer invitations. No
reviewer access has been granted by the reproduction tools. A private setting
limits future repository access; it does not retract copies already obtained.
A full image-by-image disclosure review has not been completed.

The current reproduction lock preserves historical identifiers and hashes to
verify the experiments. Do not silently rename or alter frozen inputs, source
reports, checkpoints or their manifests. A future public release needs a
separately reviewed, consistently pseudonymized export with its own manifest,
plus review of image content, metadata and history. Keep the mapping restricted.

Connection details are supplied privately. Public-facing instructions use an
SSH alias and path placeholders. Historical manifests may still contain account
paths; this change is not a claim that the whole checkout or history is sanitized.
