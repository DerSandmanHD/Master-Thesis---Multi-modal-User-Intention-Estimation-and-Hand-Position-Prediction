Download specific videos by name:
1. Get the uuids:
  aria_gen2 recording list 2>&1 \
    | grep -E 'prototype[[:space:]]+Tarik[ _][0-9]+' \
    | awk '{print $5}' \
    | sort -u \
    > tarik_uuids.txt
2. Download from the Glasses:

mkdir -p Data_collection/Data_vrs/Tarik_downloads

  while read -r uuid; do
    echo "Downloading $uuid"
    aria_gen2 recording download --uuid "$uuid" --output Data_collection/Data_vrs/Tarik_downloads/
  done < tarik_uuids.txt

Basic commands:
scp -P 443 -r * eker@134.2.17.202:~/Master-Thesis---Multi-modal-User-Intention-Estimation-and-Hand-Position-Prediction/Data_collection/
-> copy from current directory to the destination folder 

  Für deine lokalen neuen VRS-Dateien:

  rsync -avh --ignore-existing --progress \
    Data_collection/Data_vrs/Tarik_downloads/ \
    eker@134.2.17.202:/home/eker/Master-Thesis---Multi-modal-User-Intention-Estimation-and-Hand-Position-Prediction/Data_collection/Data_vrs/

  Bedeutung:

  - --ignore-existing: kopiert nur Dateien, die auf dem Cluster noch nicht existieren
  - / am Ende von Tarik_downloads/: kopiert den Inhalt des Ordners, nicht den Ordner selbst
  - Ziel ist dein Cluster-Ordner Data_collection/Data_vrs/

  Wenn du zuerst trocken testen willst:

  rsync -avhn --ignore-existing --progress \
    Data_collection/Data_vrs/Tarik_downloads/ \
    eker@134.2.17.202:/home/eker/Master-Thesis---Multi-modal-User-Intention-Estimation-and-Hand-Position-Prediction/Data_collection/Data_mp4/

  Das -n bedeutet: nur anzeigen, nichts wirklich kopieren.
