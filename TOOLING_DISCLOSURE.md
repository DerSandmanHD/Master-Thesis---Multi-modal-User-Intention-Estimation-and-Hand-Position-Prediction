# AI-assisted tooling: documented scope

The repository has been developed and reviewed with AI assistance. In the
reproduction work, OpenAI Codex assisted with repository inspection, code and
test changes, analysis of saved reports, documentation and version-control
operations. The associated thesis review workflow also included critical reviews
and proposed revisions from Anthropic Claude, supplied by the author, and
AI-assisted language revision.

This is a scope statement, not a complete attribution of every historical file
or line to a tool. Narrative phrases in a status file do not establish which
model wrote it. Existing historical protocols and their wording have not been
rewritten to conceal assistance.

AI-generated suggestions are not experimental evidence. Metric claims must be
supported by source data, saved predictions, configurations and reports. The
reproduction checks record which tests and computations actually ran; they do
not certify a full fresh-machine reproduction or institutional acceptance of
AI use. The author's thesis disclosure must accurately include all tools and
uses, including any not documented here, and follow the applicable submission
requirements. This repository note does not replace that declaration.
